# 5-Minute Recruiter Demo

1. Show architecture.
2. Open the CloudGuardian dashboard and Swagger.
3. Show a healthy AWS instance.
4. Trigger a controlled CPU/service failure.
5. Show incident detection.
6. Run diagnosis and show evidence.
7. Show that restart is blocked until approval.
8. Approve the action.
9. Execute through SSM.
10. Verify recovery.
11. Show audit trail and explain why arbitrary shell execution is prohibited.
